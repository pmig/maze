# ADR-014: Name

- **Status:** Accepted (working decision, may be revised by M0 spikes)
- **Date:** 2026-10-22

## Context

The crate `maze` on crates.io is taken (a maze generator, 2016). `mazemail` is free on crates.io, Homebrew and Debian, and `mazemail.dev` is unregistered (checked 2026-10-22). One technical name avoids a split between crate, binary and paths.

## Decision

The product name is **Maze**. Every technical identifier is **`mazemail`**: crate and binary `mazemail`, CLI `mazemail …`, env vars `MAZEMAIL_*`, token prefix `mazemail_s_`, data and config dirs `mazemail`, socket `mazemail.sock`, domain `mazemail.dev`, bundle ID `dev.mazemail.maze` (dev builds `dev.mazemail.maze-dev`), repo `pmig/mazemail`, app bundle `Maze.app`.

## Consequences

- Human-facing strings say "Maze"; identifiers say `mazemail` (AGENTS.md).
- Locally the repo is `mazemail/` with one git worktree per workspace (`mazemail/main/`, `mazemail/<workspace>/`, PLAN §2).
- Update manifests are served from `releases.mazemail.dev`.
